Generate ONE isolated green Kyber crystal shaped plaque on a genuinely transparent background. The crystal itself is the badge silhouette, not a crystal mounted on a rectangular plate. The large dark center must be calm and unobstructed so the app can overlay a white two-digit rebirth number later, readable when scaled to approximately 54 by 38 CSS pixels. No numbers, text, letters, symbols, logos, metal frame, surrounding UI, pedestal, loose shards, sparkles, smoke, scenery, or watermark.
